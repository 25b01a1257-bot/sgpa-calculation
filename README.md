# sgpa-calculation
calculation of grades and credits

This is a Java-based SGPA (Semester Grade Point Average) Calculator that helps students quickly and accurately compute their semester performance. Instead of manually calculating grade points for each subject, users can input their subject grades and credit hours, and the program automatically computes the SGPA based on standard grading formulas.

The tool is designed to be simple, lightweight, and easy to run from the command line, making it useful for students who want a quick way to track their academic performance each semester.

Key Highlights
Built entirely in Java
Simple command-line interface for input and output
Calculates SGPA based on subject-wise grade points and credit hours
Lightweight — no external dependencies required
Great for students to verify their semester results quickly
