calculation of grades and credits

🎓 SGPA Calculator

The SGPA Calculator is a simple, efficient, and user-friendly application developed to help students calculate their Semester Grade Point Average (SGPA) accurately based on the credits and grade points obtained in each subject. Instead of performing manual calculations, users can enter the required academic details, and the application automatically computes the SGPA using the standard formula. This minimizes calculation errors, saves time, and provides quick and reliable results. The project is designed with a clean and structured approach, making it easy to understand, use, and maintain for both students and beginner programmers.

This project was created as part of my learning journey to strengthen my programming skills while developing a practical solution for an everyday academic task. It demonstrates the implementation of fundamental programming concepts such as user input handling, arithmetic calculations, loops, conditional statements, and logical problem-solving. The code is organized to ensure readability and maintainability, making it suitable for educational purposes and future enhancements. In the future, this project can be extended by adding features such as CGPA calculation, grade prediction, result history, PDF report generation, and a graphical or web-based user interface, making it a more comprehensive academic management tool.
