🎓 **SGPA & CGPA Calculator** is a Java-based application designed to calculate the **Semester Grade Point Average (SGPA)** and **Cumulative Grade Point Average (CGPA)** for multiple students. The program accepts the number of students, subjects, marks, and credits as input and automatically calculates the corresponding grade points, SGPA, and CGPA. It uses Java concepts such as **Scanner, loops, conditional statements, and mathematical calculations** to provide accurate and efficient results while reducing manual calculation errors.

📊 This project is designed to simplify academic performance evaluation and demonstrate the practical application of Java programming in a real-world scenario. It provides a simple and user-friendly console-based approach for calculating student performance and can be further enhanced with features such as **database integration, GUI, semester-wise reports, and web deployment**. ☕🎯
